# Final Submission Guidelines (Ascentic AI Launchpad)

_Source: "Ascentic AI Final Project Submission.docx" (received 2026-08-22). Distilled below; structure verbatim-faithful._

## Format
- **≤20-minute video** — present as if to the judging panel (slides + live demo mix). This IS the submission; top-10 get a live demo round after elimination.
- **5 Teamtailor questions** — written info, validation details, links, evidence. **Do NOT duplicate** video content there: video = explanation + working demo; Teamtailor = quick verification of AI usage, evidence, access links.

## Required video structure
1. **Intro** — name, project title, one-line summary
2. **Problem & solution** — specific problem, specific target user, HOW YOU KNOW it's real (research/interviews), the solution, its value
3. **AI-assisted development** — which AI agents/design tools/coding assistants/workflows used; how outputs were reviewed/validated/improved
4. **Demonstration (main part)** — system walkthrough (functionality-first), technical implementation (AI features, costs, token optimization, APIs, DB, architecture), how tested/validated, challenges & limitations
5. **Future roadmap** — next improvements, missing features, what's needed for real-world readiness

## Required materials (* = mandatory)
- Demo video ***
- Presentation slides ***
- Technical or workflow diagram ***
- GitHub repository link *** — must be **accessible to judges** (⚠️ our repos are private — grant access or make public before submitting)
- Prototypes / design files (have: wireframes + clickable prototype ✅)
- Testing or user-feedback evidence (candidates: eval results #11, waitlist #15, interview findings)
- Working app / prototype / deployed link (if available)

## What maps to what (our assets)
- Problem-evidence → `wiki/idea-finalization.md` (interviews: accuracy + timing)
- AI-assisted development section → our actual workflow (Claude Code + Claude Design + this vault) — a genuinely strong story
- Diagram → supervisor/registry architecture from spec §2 (needs a drawn version)
- Prototype → `prototypes/weli-ai-mobile-prototype.dc.html`
